# Telegram-бот «Батарейка»

Готовая тестовая воронка: приветствие → 5 вопросов → один из трех результатов → оффер → заглушка оплаты → напоминание через 24 часа тем, кто не дошел до заглушки.

## Что уже работает

- подсчет баллов: А = 1, Б = 2, В = 3;
- зеленая зона: 5–8, желтая: 9–12, красная: 13–15;
- защита от повторного учета одного ответа;
- хранение прогресса и таймеров в SQLite;
- дожим через 24 часа после завершения теста;
- токен вынесен в переменные окружения;
- безопасная заглушка оплаты: деньги не списываются;
- команда `/start` перезапускает тест.

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Вставь новый токен в `BOT_TOKEN`.
4. Установи Python 3.11+ и выполни:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m app.main
```

На Windows команда активации окружения:

```powershell
.venv\Scripts\activate
```

## Проверка тестов

```bash
pip install -e '.[dev]'
pytest
```

## Тестовая оплата

Текущая версия не принимает деньги. После нажатия кнопки «Забрать доступ» бот показывает сообщение о тестовом режиме и считает, что пользователь дошел до финального шага. Поэтому ему больше не приходит 24-часовое напоминание.

Позже заглушку можно заменить реальным платежным сценарием и автоматической выдачей уроков.

## Развертывание

Проект использует long polling, поэтому подойдет любой постоянно работающий сервер или PaaS с Python 3.11+. Файл `bot.sqlite3` должен храниться на постоянном диске. Для нескольких экземпляров приложения вместо SQLite лучше использовать PostgreSQL.
